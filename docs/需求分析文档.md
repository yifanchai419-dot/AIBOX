# AI知识日报与课程生成智能体 - 需求分析文档

**版本**：V1.0  
**日期**：2026年7月23日  
**适用对象**：智能体开发实习生

---

## 一、项目背景

### 1.1 业务背景

当前，AI领域信息呈现爆炸式增长态势，每日有大量模型发布、产品更新、论文公开和行业动态涌现。公司内部团队需要高效追踪这些信息，但又面临被碎片化信息淹没的困境。

市面上已有AIHOT等热点聚合工具，能够自动从数百个信源抓取、筛选、去重、打分并分类生成日报。然而，信息获取仅是第一步，**如何将碎片化的新知识转化为可沉淀、可复用的组织资产**，才是更高阶的核心需求。

### 1.2 项目定位

本项目旨在开发一个智能体，模仿AIHOT的信息聚合能力，但不止于日报——**最终输出是结构化的1课时分享课程教案**，将一天的新知识按类别组织成可直接讲授的内容。

---

## 二、项目目标

开发一个 **"AI知识日报 → 课程生成"智能体**，每日自动完成以下工作流：

1. **信息采集**：从指定信源（RSS/API/网页）抓取过去24小时内的AI领域新动态
2. **智能筛选与分类**：对信息去重、打分、按类别归档
3. **课程化组织**：将筛选出的信息按"1课时分享课"的结构重新编排
4. **输出交付**：生成1份综合课程教案 + 按分类生成n份专题课程教案（Markdown格式）
   - 默认每日生成1份综合课程教案（涵盖所有分类）
   - 当某分类下高质量信息≥3条时，额外生成该分类的专题课程教案

## 三、功能需求

### 3.1 核心功能（必须完成）

| 功能模块 | 具体要求 | 说明 |
| :--- | :--- | :--- |
| **信息采集** | 支持至少2个信源（如RSS订阅、指定网页抓取） | 可参考AIHOT的多源采集模式，需处理抓取失败、空数据等异常 |
| **去重与筛选** | 实现内容去重、质量打分、过滤低价值信息 | 采用向量相似度比对进行去重，打分规则需包含内容质量、时效性、权威性等维度 |
| **自动分类** | 按4-5个类别自动归类 | 分类标准：模型发布 / 产品更新 / 行业动态 / 论文研究 / 技巧观点 |
| **课程大纲生成** | 将一日信息转化为结构化的1小时课程大纲 | 需包含时间分配、模块划分、讲授要点 |
| **教案输出** | 输出格式为结构化的Markdown文档 | 内容应包含：课程标题、目标、时间线、详细讲稿要点、讨论问题 |

### 3.2 重要功能（建议完成）

| 功能模块 | 具体要求 | 说明 |
| :--- | :--- | :--- |
| **日期回溯** | 支持指定日期范围生成课程 | 如"生成5月6日-5月8日的关于智能体的课程" |
| **关键词筛选** | 支持按关键词/分类筛选后再生成课程 | 提高课程内容的针对性 |
| **多格式输出** | 输出可直接导出的PPT/网页格式 | 扩展使用场景 |
| **知识库比对** | 标注每条信息与已有知识的关联关系 | 新增 / 修正 / 补充 |

## 六、输出格式规范

### 6.1 课程教案结构（Markdown）

当生成课程教案时，必须严格遵守以下结构：

1. **课程标题与基本信息**
   - 课程标题
   - 课程目标
   - 适合对象
   - 总时长：60分钟

2. **模块一：热点引入**（10分钟）
   - 当日AI领域热点概览
   - 引人入胜的开场问题

3. **模块二：核心新知讲解**（30分钟）
   - 按分类组织的核心内容
   - 详细讲稿要点
   - 关键知识点标注

4. **模块三：互动研讨与思考题**（15分钟）
   - 讨论问题设计
   - 互动环节安排

5. **模块四：总结与延伸阅读**（5分钟）
   - 课程总结
   - 延伸阅读推荐

### 6.2 分类标准

| 分类 | 定义 | 示例 |
| :--- | :--- | :--- |
| **模型发布** | 新模型发布、模型更新、模型开源 | Llama 3发布、Qwen 2更新 |
| **产品更新** | AI产品功能更新、新产品上线 | ChatGPT新功能、Copilot更新 |
| **行业动态** | AI行业新闻、政策法规、企业动态 | AI监管政策、企业融资新闻 |
| **论文研究** | 学术论文发表、研究成果公开 | NeurIPS论文、arXiv预印本 |
| **技巧观点** | 技术技巧分享、专家观点、教程 | Prompt工程技巧、AI趋势分析 |

### 6.3 去重策略

采用向量相似度比对进行去重：
- 使用ChromaDB存储历史数据向量
- 计算新数据与历史数据的余弦相似度
- 相似度阈值：≥0.85判定为重复内容

### 6.4 质量打分规则

| 维度 | 权重 | 说明 |
| :--- | :--- | :--- |
| 内容质量 | 40% | 信息完整性、深度、准确性 |
| 时效性 | 30% | 发布时间越近得分越高 |
| 权威性 | 20% | 信源可信度、作者影响力 |
| 相关性 | 10% | 与AI领域核心主题的相关度 |
